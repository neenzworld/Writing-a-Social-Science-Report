2 Part I: Panel Data & Fixed-Effects Regression

2.1 The Problem of Omitted Variable Bias

In cross-sectional OLS (Lab 3), we estimated relationships at a single point in time. However, comparing countries at one point in time suffers from Omitted Variable Bias. Canada and Nigeria differ not only in education spending, but also in climate, post-colonial state architecture, and geography.

If we run a naive “Pooled OLS” model across all countries and all years simultaneously, we treat every country-year observation as independent, ignoring country-specific baseline traits:

\[\text{Life Expectancy}_{it} = \beta_0 + \beta_1 (\text{Schooling Years}_{it}) + \varepsilon_{it}\]

2.1.1 The Fixed-Effects Solution

To isolate within-country changes over time, we introduce Entity Fixed Effects (\(\alpha_i\)) and Time Fixed Effects (\(\gamma_t\)):

\[\text{Life Expectancy}_{it} = \beta_1 (\text{Schooling Years}_{it}) + \alpha_i + \gamma_t + \varepsilon_{it}\]

  • Entity Fixed Effects (\(\alpha_i\)): Controls for all time-invariant country characteristics (geography, historical institutions, baseline culture).
  • Time Fixed Effects (\(\gamma_t\)): Controls for global time shocks that affect all countries in a given year (e.g., the 2008 Financial Crisis, 2020 COVID-19 pandemic).

2.3 Estimating Pooled OLS vs. Two-Way Fixed Effects

We can use the feols() function from the fixest package to fit three competing panel specifications:

  1. Model 1 (Pooled OLS): Ignores panel structure.
  2. Model 2 (Entity Fixed Effects): Controls for fixed country-level baseline differences (| Entity).

# Model 1: Naive Pooled OLS

3 Part II: Binary Logistic Regression & Vulnerability Traps

3.1 Conceptualizing Categorical Outcomes in Social Science

In social policy and public health, outcomes are often binary: * Is a household above or below the poverty line? (\(1\) vs \(0\)) * Is a nation experiencing a Severe Development Vulnerability Trap? (\(1\) vs \(0\))

Ordinary Least Squares (OLS) fails for binary outcomes because it predicts values below \(0\) or above \(1\). Instead, we use Binary Logistic Regression (Generalized Linear Model with a binomial family link function).

3.1.1 The Logit Model Equation

\[\ln\left(\frac{p_i}{1 - p_i}\right) = \beta_0 + \beta_1 (\text{Schooling Years}_i) + \beta_2 (\text{Poverty Rate}_i)\]

Where \(\frac{p_i}{1 - p_i}\) represents the Odds Ratio of being in a vulnerability trap.

3.2 Operationalizing the Binary Dependent Variable

We construct a binary outcome variable: vulnerability_trap. We define a country-year observation as being in a vulnerability trap (\(1\)) if its life expectancy falls below 65 years, and (\(0\)) otherwise.

Code 
# Construct binary indicator variable
logit_data <- panel_data |>
  mutate(vulnerability_trap = if_else(life_expectancy < 65, 1, 0))

# Check category distribution

3.3 Fitting the Logistic Regression Model (glm)

We fit a logistic regression model predicting the probability of falling into a vulnerability trap based on educational stock (schooling_years) and extreme poverty rates (poverty_3usd).

Code 
# Fit logistic model using glm()
logit_model <- glm(
  vulnerability_trap ~ schooling_years + poverty_3usd, 
  data = logit_data,

3.4 Converting Log-Odds to Odds Ratios (\(e^\beta\))

Raw logistic coefficients are expressed in log-odds, which are hard to interpret. By exponentiating the coefficients (\(\exp(\beta)\)), we convert them into Odds Ratios:

  • Odds Ratio > 1: Increases the likelihood of falling into the vulnerability trap.
  • Odds Ratio < 1: Decreases the likelihood of falling into the vulnerability trap (protective factor).
Code 
# Extract tidied model frame with Odds Ratios and 95% Confidence Intervals
logit_odds <- tidy(logit_model, exponentiate = TRUE, conf.int = TRUE)

logit_odds |>
  select(term, estimate, conf.low, conf.high, p.value)

An Odds Ratio of 0.65 on schooling_years means that for every additional year of average schooling accumulated by an adult population, the odds of that nation being trapped in severe health vulnerability decrease by 35% (\(1 - 0.65\)), holding poverty constant.
