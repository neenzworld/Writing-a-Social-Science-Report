1 Introduction: Moving from Description to Modeling

Welcome to Lab 3!

In Lab 1 and Lab 2, we examined development trends across time and space using panel line graphs and choropleth maps. However, social scientists do more than describe patterns. We also test theoretical relationships between variables using statistical modeling.

In this lab, we test a foundational concept in social epidemiology and political economy: The Preston Curve. Originally formulated by sociologist Samuel Preston in 1975, this relationship shows that life expectancy increases rapidly with initial reductions in absolute poverty, but displays diminishing returns as nations grow wealthier.

NoteLearning Objectives

By completing this workbook, you will learn how to: 1. Join multi-domain datasets into cross-sectional data frames for statistical modeling. 2. Fit Ordinary Least Squares (OLS) linear regression models using lm(). 3. Tidy model outputs into structured data frames using broom::tidy() and broom::glance(). 4. Extract model residuals to identify “positive outliers” (countries overperforming their economic baselines in health) and “negative outliers”.

ImportantMethodological Rule: Cross-Sectional Isolation

Unlike panel analysis where we track many years at once, cross-sectional modeling isolates a single point in time (e.g., Year = 2019) across multiple units to evaluate structural relationships without conflating temporal shocks.

2 Module 1: Constructing the Cross-Sectional Dataset

To model the relationship between material deprivation and health outcomes, we perform a relational join (inner_join()) between poverty_data.csv and life_expectancy_data.csv for a pre-pandemic cross-sectional baseline (2019).

Code 
# Step A: Load datasets using root relative directory pathing
poverty_df <- read_csv("data/poverty_data.csv")
life_exp_df <- read_csv("data/life_expectancy_data.csv")

# Step B: Filter and rename variables for 2019
poverty_2019 <- poverty_df |>
  filter(Year == 2019) |>
  rename(poverty_3usd = `Share of population in poverty ($3 a day)`) |>
  select(Entity, Code, Year, poverty_3usd)

life_exp_2019 <- life_exp_df |>
  filter(Year == 2019) |>
  rename(life_expectancy = 4) |>
  select(Entity, Code, Year, life_expectancy)

# Step C: Merge into a clean cross-sectional analytical frame
cross_section_2019 <- poverty_2019 |>
  inner_join(life_exp_2019, by = c("Entity", "Code", "Year")) |>
  filter(!is.na(poverty_3usd), !is.na(life_expectancy))

# Display head of merged modeling dataset
head(cross_section_2019)

3 Module 2: Fitting Bivariate OLS Regression Models

3.1 Linear Baseline Model (lm)

We fit a simple Bivariate Ordinary Least Squares (OLS) regression model to estimate how much life expectancy changes for every \(1\%\) increase in extreme poverty headcount.

\[\text{Life Expectancy}_i = \beta_0 + \beta_1 (\text{Poverty Rate}_i) + \varepsilon_i\]

Code 
# Fit linear model using lm()
linear_model <- lm(life_expectancy ~ poverty_3usd, data = cross_section_2019)

# Tidy model statistics into a standard dataframe using broom
tidy(linear_model)
# A tibble: 2 × 5
  term         estimate std.error statistic  p.value
  <chr>           <dbl>     <dbl>     <dbl>    <dbl>
1 (Intercept)    78.0      0.526     148.   2.19e-96
2 poverty_3usd   -0.236    0.0330     -7.15 4.28e-10
Code 
# Evaluate goodness-of-fit metrics (R-squared, Residual Standard Error)
glance(linear_model)
# A tibble: 1 × 12
  r.squared adj.r.squared sigma statistic  p.value    df logLik   AIC   BIC
      <dbl>         <dbl> <dbl>     <dbl>    <dbl> <dbl>  <dbl> <dbl> <dbl>
1     0.399         0.391  4.36      51.2 4.28e-10     1  -227.  461.  468.
# ℹ 3 more variables: deviance <dbl>, df.residual <int>, nobs <int>
NoteInterpreting the Model Coefficients
  • Intercept (\(\beta_0\)): The baseline expected life expectancy when poverty is \(0\%\).
  • Slope (\(\beta_1\)): For every \(1\%\) increase in the population living below $3.00/day, life expectancy decreases by the estimated coefficient in years.
  • \(R^2\) (R-Squared): The proportion of global variance in life expectancy explained solely by extreme poverty rates.

4.1 Visualising Linear vs. Non-Linear Fit

Let us plot our linear trendline alongside our comparative case studies using ggplot2 and ggrepel.

Code 
# Subset comparative country cases for explicit text highlighting
highlight_cases <- cross_section_2019 |>

4.2 Residual Analysis: Overperformers vs. Underperformers

A model residual (\(e_i = y_i - \hat{y}_i\)) measures the vertical distance between a country’s actual observed outcome and the outcome predicted by the regression line:

  • Positive Residual (\(e_i > 0\)) - The country achieves higher life expectancy than its economic poverty rate would predict (overperformer in public health efficiency).
  • Negative Residual (\(e_i < 0\)) - The country achieves lower life expectancy than predicted (underperformer due to health system fragmentation or disease burden).

Using broom::augment(), we can extract residuals directly into our dataset:

Code 
# Append fitted values and residuals to original dataset
model_augmented <- augment(linear_model, data = cross_section_2019)

# Inspect residual outcomes for our target comparative nations
case_residuals <- model_augmented |>
  filter(Entity %in% countries_to_compare) |>
  select(Entity, poverty_3usd, life_expectancy, .fitted, .resid) |>
  arrange(desc(.resid))

case_residuals
# A tibble: 4 × 5
  Entity        poverty_3usd life_expectancy .fitted .resid

1 Spain                0.894            83.5    77.8  5.65 
2 Canada               0.400            82.3    77.9  4.34 
3 United States        1.000            78.9    77.8  1.11 
4 Brazil               7.03             75.8    76.4 -0.574

4.3 Global South Analytical Insights: Public Policy Efficiency

Looking at the extracted residuals in the table above:

  1. State Policy Efficiency

    Nations with strong positive residuals demonstrate that targeted public interventions (e.g., universal immunization programs, primary sanitation networks, and accessible rural health posts) can decouple population health from absolute level of national wealth.

  2. Structural Disease Burden & Inequity

    Nations with deep negative residuals highlight cases where localized health crises (such as HIV prevalence or malaria endemicity) or health market fragmentation penalize life expectancy even when national economic metrics improve.
