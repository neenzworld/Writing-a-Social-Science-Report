1 Introduction: Beyond Arbitrary Spatial & Economic Binaries

Welcome to Lab 5!

In traditional comparative political economy, social scientists frequently use static classifications like “Global North vs. Global South,” “Developed vs. Developing,” or regional groupings. While useful as initial heuristics, these binaries often mask immense structural heterogeneity within groups.

In this lab, we turn to Unsupervised Machine Learning. Unsupervised methods do not rely on pre-assigned labels or target variables (\(y\)). Instead, they search for hidden patterns, geometric structures, and empirical groupings directly within the multi-dimensional feature space (\(X\)).

NoteLearning Objectives

By completing this workbook, you will learn how to: 1. Standardize (z-score scale) variables to prevent scale-bias in distance metrics. 2. Execute Principal Component Analysis (PCA) using prcomp() to reduce high-dimensional development metrics into orthogonal dimensions. 3. Evaluate component loadings and variance explained (Scree Plots). 4. Perform \(k\)-Means Clustering to partition global political economies into data-driven development typologies.

2 Module 1: Feature Engineering & Standardisation

2.1 Why Scale Variables?

Unsupervised algorithms (\(k\)-means, PCA) rely on Euclidean distance calculations:

\[d(p, q) = \sqrt{\sum_{i=1}^n (p_i - q_i)^2}\]

If one variable is measured in dollars or percentages (\(0–100\%\)) while another is measured in years of schooling (\(0–15\)), the variable with the larger numerical scale will dominate the distance calculation!

To ensure equal weighting, we transform every variable into a \(Z\)-score (mean = 0, standard deviation = 1):

\[Z = \frac{x - \mu}{\sigma}\]

Code 
# Step A: Load and extract most recent non-missing value per country
poverty_df <- read_csv("data/poverty_data.csv") |>
  rename(poverty_3usd = `Share of population in poverty ($3 a day)`) |>
  filter(!is.na(poverty_3usd)) |>
  group_by(Entity, Code) |>
  slice_max(Year, n = 1) |>
  ungroup() |>
  select(Entity, Code, poverty_3usd)

edu_df <- read_csv("data/education_data.csv") |>
  rename(schooling_years = 4) |>
  filter(!is.na(schooling_years)) |>
  group_by(Entity, Code) |>
  slice_max(Year, n = 1) |>
  ungroup() |>
  select(Entity, Code, schooling_years)

life_df <- read_csv("data/life_expectancy_data.csv") |>
  rename(life_expectancy = 4) |>
  filter(!is.na(life_expectancy)) |>
  group_by(Entity, Code) |>
  slice_max(Year, n = 1) |>
  ungroup() |>
  select(Entity, Code, life_expectancy)

# Step B: Relational join on Entity and Code
cluster_raw <- life_df |>
  inner_join(edu_df, by = c("Entity", "Code")) |>
  inner_join(poverty_df, by = c("Entity", "Code")) |>
  distinct(Entity, .keep_all = TRUE)

# Step C: Extract numeric feature matrix
feature_df <- cluster_raw |>
  select(life_expectancy, schooling_years, poverty_3usd) |>
  as.data.frame()

rownames(feature_df) <- cluster_raw$Entity

# Manual Z-score matrix for k-means
scaled_matrix <- scale(feature_df)

# View top of scaled feature space
head(scaled_matrix)

3 Module 2: Principal Component Analysis (PCA)

3.1 Compressing High-Dimensional Development Space

Principal Component Analysis (PCA) transforms correlated features into a smaller set of uncorrelated, orthogonal variables called Principal Components (PC1, PC2, etc.):

  • PC1 captures the maximum possible variance across the global development features.
  • PC2: captures the maximum remaining variance orthogonal (uncorrelated) to PC1.
Code 
# Run PCA on scaled matrix
pca_result <- prcomp(scaled_matrix, center = FALSE, scale. = FALSE)

# Inspect standard deviations and proportion of variance explained
summary(pca_result)
Importance of components:
                          PC1    PC2     PC3
Standard deviation     1.5773 0.5591 0.44675
Proportion of Variance 0.8293 0.1042 0.06653
Cumulative Proportion  0.8293 0.9335 1.00000

3.2 Inspecting Variable Loadings

Component loadings show how much each original indicator contributes to each principal component.

Code 
# Extract rotation matrix (loadings)
pca_result$rotation
                       PC1       PC2        PC3
life_expectancy -0.5901422 0.1761358 -0.7878505
schooling_years -0.5766681 0.5909889  0.5640798
poverty_3usd     0.5649655 0.7872155 -0.2471955
NoteInterpreting PC1 & PC2
  • PC1 (Development Index)-High positive loadings on life_expectancy and schooling_years, with a strong negative loading on poverty_3usd. PC1 effectively acts as an empirical composite “Human Development Progress” axis!
  • PC2 (Structural Divergence)-Captures secondary variance where health and education metrics diverge from absolute income poverty levels.

4 Module 3: PCA Biplot Visualisation

We project all global countries onto the two-dimensional PCA feature space defined by PC1 and PC2, highlighting our eight comparative case study nations.

Code 
# Extract country coordinates along principal components
pca_scores <- as.data.frame(pca_result$x)
pca_scores$Entity <- rownames(pca_scores)

# Highlight comparative countries
highlight_pca <- pca_scores |>
  filter(Entity %in% countries_to_compare)

ggplot(pca_scores, aes(x = PC1, y = PC2)) +

5 Module 4: \(k\)-Means Clustering Analysis

While PCA collapses continuous dimensions, \(k\)-Means Clustering partitions nations into \(k\) discrete structural clusters by minimizing within-cluster sum of squares (WCSS).

We partition the global data into \(k = 3\) Empirical Development Clusters.

Code 
# Set seed for reproducible cluster initialization
set.seed(1234)

# Fit k-means with k = 3
kmeans_result <- kmeans(scaled_matrix, centers = 3, nstart = 25)

# Append cluster assignments back to original data
cluster_raw$cluster <- as.factor(kmeans_result$cluster)
pca_scores$cluster  <- as.factor(kmeans_result$cluster)

# Inspect cluster centroids (in z-score units)
kmeans_result$centers
  life_expectancy schooling_years poverty_3usd
1     -1.38324228      -1.3064083    1.5647700
2     -0.09315897      -0.0913109   -0.3840766
3      0.99814781       0.9464468   -0.5784944

5.2 Global South Analytical Insights: Deconstructing Typologies

Looking at Figure 2 and the cluster centroids:

  1. Beyond “North vs. South”: Notice how middle-income Global South economies like Brazil and Jamaica cluster closer to post-industrial economies (Canada, Spain) along PC1 than they do to severe absolute deprivation contexts.
  2. Structural Heterogeneity: Unsupervised clustering reveals that the “Global South” is not a monolith. Post-colonial economies split into distinct structural clusters: emerging social-protection states vs. high-poverty structural trap contexts.
