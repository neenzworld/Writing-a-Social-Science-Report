1 Introduction: Spatial Analysis in Social Science

Welcome to Lab 2!

In Lab 1, we examined development indicators across time using panel line graphs. However, national development is not evenly distributed across space. Geographic proximity, regional trade blocs, historical colonial boundaries and ecological zones heavily shape human development outcomes.

In this lab, we transition from time-series charts to choropleth maps (maps where geographical areas are coloured according to an underlying metric).

Apply cartographic projections suitable for global analysis.

2 Module 1: Fetching Spatial Geometries & Projections

2.1 Spatial Data in R: Simple Features (sf)

In GIS (Geographic Information Systems), spatial data consists of: * Attributes: The tabular numerical metrics (e.g., life expectancy in years). * Geometries: Coordinates defining lines and polygons that draw borders on a map.

In R, the sf package stores geometries inside a dedicated column named geometry.

Code 
# Fetch medium-resolution world country map geometries
world_map <- ne_countries(scale = "medium", returnclass = "sf")

# Inspect spatial dataframe structure
glimpse(world_map |> select(name, iso_a3, continent, geometry))

ImportantCartographic Projections & Northern Bias

Because the Earth is a 3D sphere, flattening it onto a 2D screen requires a mathematical projection.

The traditional Mercator projection distorts land area at high latitudes, visually expanding North America and Europe while shrinking Africa, South America, and South Asia. From a Global South perspective, projection choice is inherently political. It shapes how spatial scales are perceived.

3 Module 2: Mapping Global Health Inequalities

3.1 Merging Geometries with Tabular Data

We can join our spatial world_map object with life_expectancy_data.csv using the 3-letter ISO country code (iso_a3 in sf and Code in OWID).

Code 
# Import health metrics from root data folder
life_exp_data <- read_csv("data/life_expectancy_data.csv")

# Isolate 2021 health metrics
life_exp_2021 <- life_exp_data |>
  filter(Year == 2021) |>
  rename(life_expectancy = 4)

# Execute spatial left join
world_health_map <- world_map |>
  filter(continent != "Antarctica") |>
  left_join(life_exp_2021, by = c("iso_a3" = "Code"))

3.2 Global Health Choropleth Map

Code 
ggplot(world_health_map) +
  geom_sf(aes(fill = life_expectancy), color = "white", size = 0.1) +
  scale_fill_viridis_c(
    option = "magma",
    na.value = "grey90",
    name = "Life Expectancy (Years)"
  ) +
  labs(
    title = "Global Life Expectancy Inequities (2021)",
    subtitle = "Period life expectancy at birth across national economies",
    caption = "Source: Our World in Data / UN World Population Prospects."
  ) +
  theme_minimal() +
  theme(
    legend.position = "bottom",
    legend.key.width = unit(2, "cm"),
    plot.title = element_text(face = "bold", size = 14),
    axis.text = element_blank(),
    axis.ticks = element_blank(),
    panel.grid = element_blank()
  )

4 Module 3: Comparative Spatial Zoom — Regional Focus

We can filter our spatial dataset to examine intra-regional variance across Latin America & Caribbean and Sub-Saharan Africa.

Code 
regional_map <- world_health_map |>
  filter(continent %in% c("Africa", "South America"))

  scale_fill_viridis_c(option = "viridis", na.value = "grey85", name = "Years") +
  facet_wrap(~continent) +
  labs(
    title = "Intra-Regional Health Divergence (2021)",
    subtitle = "Comparative spatial breakdown across Africa and South America",

# Module 2: Mapping Global Health Inequalities

## Merging Geometries with Tabular Data

We can join our spatial `world_map` object with `life_expectancy_data.csv` using the 3-letter ISO country code (`iso_a3` in `sf` and `Code` in OWID).

```{r}
#| label: join-health-data
#| message: false
#| warning: false

# Import health metrics from root data folder
life_exp_data <- read_csv("data/life_expectancy_data.csv")

# Isolate 2021 health metrics
life_exp_2021 <- life_exp_data |>
  filter(Year == 2021) |>
```
